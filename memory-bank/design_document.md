# 오목 게임 기획서 (Design Document)

## 1. 게임 개요

웹 브라우저에서 플레이할 수 있는 인간 대 AI 오목 게임.
플레이어(흑)가 먼저 돌을 놓고, AI(백)가 이에 응수하는 방식으로 진행된다.

---

## 2. 게임 규칙

### 기본 규칙
- 보드 크기: **15×15**
- 흑(플레이어)이 항상 선공
- 가로 / 세로 / 대각선 방향으로 **정확히 5개**를 연속으로 놓으면 승리
- 6개 이상 연속(장목)은 승리로 인정하지 않음

### 금수 (렌주 룰 적용 — 흑에만 적용)
| 금수 종류 | 설명 |
|-----------|------|
| 33 | 열린 3을 두 방향 이상 동시에 만드는 수 금지 |
| 44 | 4를 두 방향 이상 동시에 만드는 수 금지 |
| 장목 | 6개 이상 연속 금지 |

- 금수 위치에는 돌을 놓을 수 없으며, 해당 칸에 커서를 올리면 시각적으로 표시
- AI(백)에게는 금수 미적용

---

## 3. AI 플레이어

### 난이도
| 레벨 | 설명 |
|------|------|
| 쉬움 | 랜덤 배치 + 단순 위협 차단 |
| 보통 | 미니맥스 알고리즘 (탐색 깊이 3) |
| 어려움 | 미니맥스 + 알파-베타 가지치기 (탐색 깊이 5) |

- 게임 시작 전 난이도 선택
- AI는 항상 백(후공)

### AI 우선순위 (보통/어려움 공통)
1. 즉시 승리 가능한 수
2. 플레이어의 즉시 승리 차단
3. 4 연속 만들기
4. 플레이어의 4 연속 차단
5. 3 연속 만들기
6. 유리한 위치 점령

## 4. UI / UX

### 화면 구성
```
┌─────────────────────────────────┐
│  OMOK         난이도: [보통 ▼]  │  ← 헤더
├─────────────────────────────────┤
│                                 │
│      15×15 오목판               │  ← 게임 보드
│                                 │
├─────────────────────────────────┤
│  ● 플레이어 차례  [무르기] [재시작] │  ← 상태 바
└─────────────────────────────────┘
```

### 보드
- 격자선 위에 돌을 놓는 방식 (교차점에 착수)
- 흑돌: 검정, 백돌: 흰색 (테두리 포함)
- 마지막으로 놓인 돌에 마킹 표시 (작은 점)
- 금수 위치 호버 시 빨간색 X 표시

### 게임 흐름
1. 페이지 진입 → 난이도 선택 모달
2. 확인 → 게임 시작 (흑 선공)
3. 플레이어 착수 → AI 응수 (AI 생각 중 딜레이 0.3~0.8초)
4. 승리/무승부 조건 충족 → 결과 모달 표시
5. 결과 모달에서 재시작 또는 난이도 변경 선택

### 결과 처리
- 승리 시: 이긴 돌 5개 하이라이트 + "플레이어 승리!" / "AI 승리!" 모달
- 무승부: 보드가 가득 찼을 때 "무승부!" 모달
- 무르기: 플레이어와 AI의 마지막 수를 함께 되돌림 (1회씩 가능)

## 5. 기술 스택

| 항목 | 선택 |
|------|------|
| 언어 | HTML5 / CSS3 / Vanilla JavaScript (ES6+) |
| 렌더링 | Canvas API 또는 CSS Grid |
| 빌드 도구 | 없음 (단일 파일 또는 소수 파일 구성) |
| 외부 라이브러리 | 없음 |
| 배포 | 정적 파일 (GitHub Pages 등) |

## 6. 파일 구조 (안)

```
omok/
├── index.html
├── style.css
└── js/
    ├── main.js       # 진입점, 이벤트 초기화
    ├── board.js      # 보드 상태 관리, 렌더링
```
